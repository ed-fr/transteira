# User guides / Guides utilisateur

One guide per profile, in English and in French. The integrated help of TransTeira is generated
from these files: the same text is shown in the application under `/help` (entity hosts) and
`/admin/help` (admin host), opened at the right section by the **Help** link at the bottom of each
screen and by the "?" icon next to the title of the complex screens.

Un guide par profil, en anglais et en français. L’aide intégrée de TransTeira est générée à partir
de ces fichiers : le même texte est affiché dans l’application sous `/help` (adresses des entités)
et `/admin/help` (adresse d’administration), ouvert à la bonne section par le lien **Aide** en bas
de chaque écran et par l’icône « ? » à côté du titre des écrans complexes.

## English

- [Sending files](en/depositor.md): for people who send files (internal users and invited
  external people): identification by code, the transfer form and its options, upload progress
  and resume, antivirus analysis, invitations and common problems.
- [Receiving files](en/recipient.md): for recipients: download page, password, single files or
  ZIP archive, SHA-256 fingerprints, antivirus status, expiry.
- [Delegated administrator guide](en/delegated-admin.md): for the administrators of one or more
  entities: sign-in and two-factor authentication, entity configuration (branding, network, SMTP,
  email templates, legal texts) and operations (transfers, invitations, blocklist, API tokens,
  audit log, statistics, personal data).
- [Super administrator guide](en/super-admin.md): for the operator of the instance: first launch,
  entities and administrator accounts, system screens, maintenance mode, disk alert, global audit
  log and master key rotation.

## Français

- [Envoyer des fichiers](fr/depositor.md) : pour les personnes qui envoient des fichiers
  (utilisateurs internes et personnes externes invitées) : identification par code, formulaire du
  transfert et ses options, progression et reprise de l’envoi, analyse antivirus, invitations et
  problèmes courants.
- [Recevoir des fichiers](fr/recipient.md) : pour les destinataires : page de téléchargement,
  mot de passe, fichiers un par un ou archive ZIP, empreintes SHA-256, état de l’analyse
  antivirus, expiration.
- [Guide de l’administrateur délégué](fr/delegated-admin.md) : pour les administrateurs d’une ou
  plusieurs entités : connexion et double authentification, configuration de l’entité (habillage,
  réseau, SMTP, modèles de mails, mentions légales) et opérations (transferts, invitations, liste
  de blocage, jetons d’API, journal d’audit, statistiques, données personnelles).
- [Guide du super administrateur](fr/super-admin.md) : pour l’exploitant de l’instance : premier
  lancement, entités et comptes administrateurs, écrans du système, mode maintenance, alerte
  d’espace disque, journal d’audit global et rotation de la clé maître.

## Screenshots / Captures d’écran

The images of `screenshots/en/` and `screenshots/fr/` are generated by the end-to-end tests
(Playwright, deterministic data, 1280 x 800) and listed in `screenshots/manifest.json`; never edit
them by hand. After a change of the interface, regenerate them from the repository root with
`make screenshots` (needs Docker), then check them with `make screenshots-check` (also part of
`make check`).

Les images de `screenshots/en/` et `screenshots/fr/` sont générées par les tests de bout en bout
(Playwright, données déterministes, 1280 x 800) et listées dans `screenshots/manifest.json` ; ne
les modifiez jamais à la main. Après une modification de l’interface, régénérez-les depuis la
racine du dépôt avec `make screenshots` (Docker requis), puis vérifiez-les avec
`make screenshots-check` (inclus dans `make check`).

## Writing the guides / Rédaction des guides

The guides use a strict Markdown subset (no HTML, no tables, no external links), checked when the
help is generated: see the section "Integrated help" of [`web/README.md`](../../web/README.md),
which also explains how to add a help topic. Both languages must keep the same topics. Two
directives, each as an HTML comment alone on its line, personalise the guides per entity:
`<!-- rules: summary|limits|levels -->` (replaced in the application by the real rules of the
entity) and `<!-- when: feature -->` before a level 2 or 3 heading (section hidden when the entity
has the feature off). They render nothing on GitHub; both languages must carry them at the same
places.

Les guides utilisent un sous-ensemble strict de Markdown (ni HTML, ni tableau, ni lien externe),
vérifié à la génération de l’aide : voir la section « Integrated help » de
[`web/README.md`](../../web/README.md), qui explique aussi comment ajouter un sujet d’aide. Les deux
langues doivent garder les mêmes sujets. Deux directives, chacune en commentaire HTML seul sur sa
ligne, personnalisent les guides par entité : `<!-- rules: summary|limits|levels -->` (remplacée
dans l’application par les règles réelles de l’entité) et `<!-- when: fonctionnalité -->` avant un
titre de niveau 2 ou 3 (section masquée si l’entité a désactivé la fonctionnalité). Elles
n’affichent rien sur GitHub ; les deux langues doivent les porter aux mêmes endroits.
